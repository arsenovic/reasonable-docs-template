# About

mypkg is a stand-in: a small package that makes, adds and plots signals, so that
[reasonable-docs-template](https://github.com/arsenovic/reasonable-docs-template) has something
to document. Copy the template, replace mypkg with your package, and keep the docs' layout:
guides, a gallery of examples, an API reference, and these project pages.

The docs are built with:

- [Sphinx](https://www.sphinx-doc.org/), and [MyST-NB](https://myst-nb.readthedocs.io/) for the
  notebooks;
- the [shibuya-page](https://github.com/arsenovic/shibuya-page) theme, a child of
  [Shibuya](https://shibuya.lepture.com/);
- [plotly](https://plotly.com/python/), for the interactive plots.
